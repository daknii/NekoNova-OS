# AI and Authorship Policy

## Position

NekoNova is a human-led project. Its design decisions, architecture,
production implementation, testing, and releases should be directed and
understood by the people responsible for maintaining it.

The project's current policy is **not to use generative AI to produce
NekoNova's production code or original visual assets**. This is a
deliberate project constraint, not a claim that every use of AI in
software development is inherently harmful.

## What this means

-   Production code is written and reviewed by project contributors.
-   Original project artwork, icons, and other branded assets are
    created by people or sourced under appropriate licenses.
-   Existing open-source software and ordinary non-generative developer
    tools remain welcome.
-   Contributors should not submit generated code or artwork as their
    own work.
-   External contributions must follow the same policy if they are to
    become part of the project.

## Research and assistance

The project prioritizes primary documentation, source code, issue
trackers, and direct testing. If a contributor uses AI privately for
general explanation or brainstorming, they remain responsible for
verifying the information and writing the submitted implementation
themselves.

Do not paste secrets, credentials, private user data, or non-public
security information into external services.

## Transparency

NekoNova will not claim that a feature is hand-written, tested, secure,
or complete unless that claim is accurate. If project policy changes,
the change should be discussed publicly and documented here.

## Why this policy exists

NekoNova aims to practice deliberate craftsmanship, maintainability, and
accountability. The point is not to create marketing drama around AI; it
is to make sure that the people building the project understand and
stand behind what they ship.

## Slogan

> Do you like AI?\
> We neither.\
> NekoNova OS.

The slogan is intentionally provocative. The policy above clarifies what
it means in practice.
